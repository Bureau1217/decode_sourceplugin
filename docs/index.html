Privacy policy — Source Reliability Plugin (DE.CO.DE)

Last updated: 2026-10-23

What this extension does

Source Reliability Plugin ("the extension") displays a trust score next to sources in Google search results, using a bundled reliability database. It lets you record whether you agree or disagree with a given score, and suggest sources that are not yet in the database.

Data the extension reads

The extension reads the page structure of google.com search results (result titles and links) in order to match each result's domain against its reliability database. It does not read your search query text, your browsing history on other sites, or the content of the pages you visit beyond google.com search result listings.

Data the extension stores

  • Whether badges are enabled (chrome.storage.local)
  • Your agree/disagree votes, keyed by domain (chrome.storage.local)
  • Sources you suggest via "Rate this source" (chrome.storage.local)

This data is stored locally in your browser only. It is not transmitted to any server; the extension has no backend in this version. Uninstalling the extension deletes it.

Data the extension shares

None. No analytics, no third-party requests, no remote code.

Changes

If a future version connects to a content management system to keep the reliability database up to date, this policy will be updated to describe what that service receives before that version ships.
